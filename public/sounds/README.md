# Alert Sounds

Please add an alert sound file named `attention-alert.mp3` to this directory for the attention tracking feature to work properly.

You can find free notification sounds at:

- [Freesound](https://freesound.org/search/?q=alert+notification&f=&s=score+desc&advanced=0&g=1)
- [Mixkit](https://mixkit.co/free-sound-effects/notification/)
- [SoundBible](https://soundbible.com/tags-alert.html)

The sound should be short (1-2 seconds) and noticeable without being too jarring.
